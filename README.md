# 統計検定2級 対策アプリ

ブラウザとスマホで動く、統計検定2級の問題演習アプリです。ホーム画面に追加するとアプリとして使え、オフラインでも動きます(PWA)。

## 機能

- **模擬試験(CBT形式)**: 全8分野からほぼ均等に35問・90分(変更可)。問題一覧からの移動、見直し(自信なし)の目印、付表・電卓、提出前の未回答チェック。100点満点で採点し、60点を合格の目安として表示。途中で閉じても続きから再開できる
- **分野別演習**: 収録問題400問+自動生成問題から出題。1問ごとに正誤と解説
- **自動生成問題(61種類)**: 数値が毎回変わる。過去問(2021年6月)の出題形式を分析して作成し、5択(①〜⑤)、「記述Ⅰ〜Ⅲの正しい組合せ」、「(ア)〜(ウ)の組合せ」、回帰分析の出力表・分散分析表の穴埋め、付表を引く問題がある。分析は [docs/past-exam-patterns.md](docs/past-exam-patterns.md)
- **図表の読み取り問題**: ヒストグラム、箱ひげ図、散布図(2つの比較を含む)、折れ線グラフ、指数のグラフ、分割表、同時確率表、二項分布の確率表、回帰の出力表、分散分析表(SVG・表で描画)
- **選択肢のシャッフル**: 収録問題は出題のたびに選択肢の順番を入れ替える。自動生成問題は数値の小さい順に並べ、正解の位置が偏らないようにしている
- **間隔反復(今日の復習)**: 不正解は当日中、自信なしの正解は翌日、自信を持って正解すると 3→7→14→30→60日後に再出題。足りない分は苦手分野から補う。自動生成問題は数値を変えて出し直す
- **自信なし・ブックマーク**: 各問題に⚐自信なし・☆ブックマークを付けられ、目印ごとに復習できる
- **付表**: 標準正規分布の上側確率、t分布・χ²分布のパーセント点、F分布の上側5%・2.5%点(scipyで計算)
- **公式・用語まとめ**: 8分野の公式と用語。各問題の解説から該当する分野の公式を開ける
- **数式表示**: KaTeX を同梱(オフライン可)。問題・解説・取り込みデータの `$...$` を数式として表示

記録・目印はブラウザの localStorage に保存されます。別の端末に移すときは「データ」タブのバックアップを使ってください。

## 使い方

```sh
npm start          # http://localhost:8000/ で起動
```

### スマホで使う(アプリとしてインストール)

Service Worker は https(または localhost)でのみ動くため、GitHub Pages などで公開してからスマホで開きます。

- **iPhone(Safari)**: 共有ボタン →「ホーム画面に追加」
- **Android(Chrome)**: メニュー →「アプリをインストール」または「ホーム画面に追加」

一度開けば、以後はオフラインでも使えます。

## 開発

| コマンド | 内容 |
| --- | --- |
| `npm run build` | `data/questions.json` を検証し、ブラウザ用の `data/questions.js` を生成 |
| `npm run tables` | 付表 `data/tables.js` を生成(要 scipy) |
| `npm test` | 自動生成問題を各300回生成し、不正な問題や正解位置の偏りがないか確認 |

ファイルを更新して公開するときは、`sw.js` の `VERSION` を変えてください(スマホ側のキャッシュが更新されます)。

### 問題データの形式

```json
{"id": "yoso-01", "field": "データの基礎", "question": "問題文($...$ で数式)", "choices": ["...", "..."], "answer": 3, "explanation": "解説"}
```

`answer` は正解の番号(1始まり)。任意で `exam`(試験回)、`no`(問題番号)、`source`(出典表記)、`figure`(図表の data:image URI)。

### 自動生成問題を追加する

`js/gen.js` の `def(id, 分野, 題名, R => {...})` で追加します。`R` は乱数(`R.ri(a,b)`、`R.pick(配列)` など)で、`mc(R, 正解, [典型的な誤答...], {d: 小数桁})` を使うと5択を作れます。

## 構成

```
index.html               画面
manifest.webmanifest     PWA設定
sw.js                    Service Worker(オフライン対応)
css/style.css            スタイル(ダークモード対応)
js/app.js                アプリ本体(出題・模試・間隔反復・付表・電卓)
js/gen.js                自動生成問題(61種類)
js/formulas.js           公式・用語まとめ
data/questions.json      収録問題(編集用)
data/questions.js        収録問題(自動生成)
data/tables.js           付表(自動生成)
vendor/katex/            KaTeX 0.16.11(MITライセンス)
icons/                   アプリアイコン
scripts/                 生成・検証・ローカルサーバー
```

## 注意

- 収録問題・自動生成問題はすべてAIが作成した練習問題で、過去問ではありません
- 試験の形式(CBT・約35問・90分・60点合格など)は一般に公開されている情報に基づく目安です。最新の情報は統計検定の公式サイトで確認してください
